Three breach entries for make.fun ai-excited-01 ("Make the AI judge excited") — each a creature bursting out of the thing that was supposed to contain it:

- **Boar from a piggy bank** — a wild boar charges out of a shattered pink ceramic piggy bank, gold coins arcing along the diagonal.
- **Storm-deer from a barometer** — a stag made of storm cloud and lightning bursts out of a shattered brass barometer.
- **Mantis from a thimble** — a colossal bioluminescent praying mantis erupts out of a tiny silver sewing thimble.

Each commit in this repo sets `entry.png` to one entry; `main.ts` copies it to the output directory.

## Run it

```sh
node main.ts
```
